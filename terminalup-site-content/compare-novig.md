# TerminalUp vs Novig

**Novig is one sports exchange. TerminalUp is trading software that puts Novig on one board with other sportsbooks, betting exchanges and prediction markets and routes each order to the best available price.** Novig is live on TerminalUp. When Novig has the best price, the order routes there. When another venue has it, the order goes there instead. You fund one TerminalUp account. Orders route to venues from it.

| | Novig | TerminalUp |
| --- | --- | --- |
| What it is | Peer-to-peer sports exchange | Cross-venue trading terminal with order routing |
| Prices you see | Novig's order book | Novig next to the other venues in the directory |
| Where the order goes | Novig | The venue with the best available price |
| Accounts you need | A Novig account | One TerminalUp account |
| Fees | Set by Novig | 0.5% commission on trades, no subscription |
| Access | Set by Novig | Invite-only, $10,000 minimum deposit |

## This is not either/or

TerminalUp does not compete with Novig for your deposit. It sends orders to Novig when Novig has the price. The question is whether you check Novig against other venues by hand or let routing do it.

## Choose Novig directly if

You only want Novig's markets and you trade below TerminalUp's $10,000 minimum.

## Choose TerminalUp if

You trade with size and want Novig compared with other venues on every order, from one account.

## FAQ

**Can I trade Novig through TerminalUp?**
Yes. Novig is a live venue on TerminalUp.

**Is TerminalUp an exchange?**
No. It is trading software that routes orders to exchanges, sportsbooks and prediction markets. It holds no book and never takes the other side of a trade.

**Do I need my own Novig account?**
No. You fund one TerminalUp account. Orders route to venues from it.
