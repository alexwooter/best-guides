# TerminalUp vs ProphetX

**ProphetX is one exchange. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** ProphetX is a US sports exchange with an order book where users post and take prices. ProphetX is listed as a confirmed venue in the TerminalUp directory. You fund one TerminalUp account. Orders route to venues from it.

| | ProphetX | TerminalUp |
| --- | --- | --- |
| What it is | Peer-to-peer sports exchange | Cross-venue trading terminal with order routing |
| Prices you see | ProphetX's order book | Prices across the venues in its directory |
| Where the order goes | ProphetX | The venue with the best available price |
| Accounts you need | A ProphetX account | One TerminalUp account |
| Fees | Set by ProphetX | 0.5% commission on trades, no subscription |
| Access | Set by ProphetX | Invite-only, $10,000 minimum deposit |

## Choose ProphetX directly if

You want to post and take prices on ProphetX's order book alone.

## Choose TerminalUp if

You trade with size and want prices compared across venues on every order, from one account.

## FAQ

**Is ProphetX on TerminalUp?**
ProphetX is listed as a confirmed venue in the TerminalUp directory. The current list is at https://terminalup.com/partners.

**Is TerminalUp an exchange?**
No. TerminalUp is trading software. It routes orders to sportsbooks, betting exchanges and prediction markets, holds no book and never takes the other side of a trade.

**What does TerminalUp cost?**
0.5% commission on trades, no subscription, with a $10,000 minimum deposit.
