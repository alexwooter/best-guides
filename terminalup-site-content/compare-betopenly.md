# TerminalUp vs BetOpenly

**BetOpenly is a peer-to-peer betting platform with no bookmaker in the middle. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** BetOpenly is listed in the TerminalUp directory. You fund one TerminalUp account. Orders route to venues from it.

## What BetOpenly does well

BetOpenly matches every bet directly between users, with no bookmaker in the middle.

- No bookmaker: prices are set by the market.
- You can take either side of any market.
- A broad menu, from football and basketball to tennis, esports and fights.

## Not either/or

TerminalUp does not compete with BetOpenly. It is software that sits on top of venues and compares their prices. The current directory is at https://terminalup.com/partners.

| | BetOpenly | TerminalUp |
| --- | --- | --- |
| What it is | Peer-to-peer betting platform | Cross-venue trading terminal with order routing |
| Prices you see | BetOpenly's order book | Prices across the venues in its directory |
| Where the order goes | BetOpenly | The venue with the best available price |
| Accounts you need | A BetOpenly account | One TerminalUp account |
| Fees | Set by BetOpenly | 0.5% commission on trades, no subscription |
| Access | Set by BetOpenly | Invite-only, $10,000 minimum deposit |

## Choose BetOpenly directly if

You want to create or take peer-to-peer bets on BetOpenly alone.

## Choose TerminalUp if

You trade with size and want prices compared across venues on every order, from one account.

## FAQ

**Is BetOpenly on TerminalUp?**
BetOpenly is listed in the TerminalUp directory. The current list is at https://terminalup.com/partners.

**Is TerminalUp an exchange?**
No. TerminalUp is trading software. It routes orders to sportsbooks, betting exchanges and prediction markets, holds no book and never takes the other side of a trade.

**What does TerminalUp cost?**
0.5% commission on trades, no subscription, with a $10,000 minimum deposit.
