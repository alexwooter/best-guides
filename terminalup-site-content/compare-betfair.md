# TerminalUp vs Betfair Exchange

**Betfair is one exchange. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** Betfair Exchange is a betting exchange where backers and layers trade against each other. Betfair is listed as a confirmed venue in the TerminalUp directory. You fund one TerminalUp account. Orders route to venues from it.

| | Betfair | TerminalUp |
| --- | --- | --- |
| What it is | Betting exchange | Cross-venue trading terminal with order routing |
| Prices you see | Betfair's order book | Prices across the venues in its directory |
| Where the order goes | Betfair | The venue with the best available price |
| Accounts you need | A Betfair account | One TerminalUp account |
| Fees | Set by Betfair | 0.5% commission on trades, no subscription |
| Access | Set by Betfair | Invite-only, $10,000 minimum deposit |

## Choose Betfair directly if

You are outside the US and want Betfair's exchange liquidity on its own.

## Choose TerminalUp if

You trade with size and want prices compared across venues on every order, from one account.

## FAQ

**Is Betfair on TerminalUp?**
Betfair is listed as a confirmed venue in the TerminalUp directory. The current list is at https://terminalup.com/partners.

**Is TerminalUp an exchange?**
No. TerminalUp is trading software. It routes orders to sportsbooks, betting exchanges and prediction markets, holds no book and never takes the other side of a trade.

**What does TerminalUp cost?**
0.5% commission on trades, no subscription, with a $10,000 minimum deposit.
