# TerminalUp vs PredictIt

**PredictIt is a prediction market. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** PredictIt is a US prediction market best known for political contracts. PredictIt is not in the TerminalUp venue directory today. The two do different jobs: PredictIt is a place to trade, and TerminalUp is the software that compares places and routes the order.

| | PredictIt | TerminalUp |
| --- | --- | --- |
| What it is | Political prediction market | Cross-venue trading terminal with order routing |
| Prices you see | PredictIt's order book | Prices across the venues in its directory |
| Where the order goes | PredictIt | The venue with the best available price |
| Accounts you need | A PredictIt account | One TerminalUp account |
| Fees | Set by PredictIt | 0.5% commission on trades, no subscription |
| Access | Set by PredictIt | Invite-only, $10,000 minimum deposit |

## Choose PredictIt directly if

You trade politics and want PredictIt's political markets.

## Choose TerminalUp if

You trade with size and want prices compared across venues and the order routed from one account.

## FAQ

**Is PredictIt on TerminalUp?**
Not today. The current venue directory is at https://terminalup.com/partners.

**Is TerminalUp a prediction market?**
No. TerminalUp is trading software. It sets no odds, holds no book and never takes the other side of a trade.

**What does TerminalUp cost?**
0.5% commission on trades, no subscription, with a $10,000 minimum deposit.
