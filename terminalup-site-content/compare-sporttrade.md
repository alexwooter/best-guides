# TerminalUp vs Sporttrade

**Sporttrade is an exchange. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** Sporttrade is a regulated US sports exchange where outcomes trade as contracts priced from 0 to 100. Sporttrade is not in the TerminalUp venue directory today. The two do different jobs: Sporttrade is a place to trade, and TerminalUp is the software that compares places and routes the order.

| | Sporttrade | TerminalUp |
| --- | --- | --- |
| What it is | Regulated US sports exchange | Cross-venue trading terminal with order routing |
| Prices you see | Sporttrade's order book | Prices across the venues in its directory |
| Where the order goes | Sporttrade | The venue with the best available price |
| Accounts you need | A Sporttrade account | One TerminalUp account |
| Fees | Set by Sporttrade | 0.5% commission on trades, no subscription |
| Access | Set by Sporttrade | Invite-only, $10,000 minimum deposit |

## Choose Sporttrade directly if

You are in one of Sporttrade's states and want to trade in and out of positions on its exchange.

## Choose TerminalUp if

You trade with size and want prices compared across venues and the order routed from one account.

**Is Sporttrade on TerminalUp?**

**Is TerminalUp an exchange?**
No. TerminalUp is trading software. It sets no odds, holds no book and never takes the other side of a trade.

0.5% commission on trades, no subscription, with a $10,000 minimum deposit.
