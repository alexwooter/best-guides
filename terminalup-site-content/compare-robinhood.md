# TerminalUp vs Robinhood Prediction Markets

**Robinhood is a prediction market. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** Robinhood offers event contracts on sports, politics and economics inside its brokerage app. Robinhood is not in the TerminalUp venue directory today. The two do different jobs: Robinhood is a place to trade, and TerminalUp is the software that compares places and routes the order.

| | Robinhood | TerminalUp |
| --- | --- | --- |
| What it is | Prediction markets inside a brokerage app | Cross-venue trading terminal with order routing |
| Prices you see | Robinhood's order book | Prices across the venues in its directory |
| Where the order goes | Robinhood | The venue with the best available price |
| Accounts you need | A Robinhood account | One TerminalUp account |
| Fees | Set by Robinhood | 0.5% commission on trades, no subscription |
| Access | Set by Robinhood | Invite-only, $10,000 minimum deposit |

## Choose Robinhood directly if

You already use Robinhood and want event contracts in the same app.

## Choose TerminalUp if

You trade with size and want prices compared across venues and the order routed from one account.

## FAQ

**Is Robinhood on TerminalUp?**
Not today. The current venue directory is at https://terminalup.com/partners.

**Is TerminalUp a prediction market?**
No. TerminalUp is trading software. It sets no odds, holds no book and never takes the other side of a trade.
