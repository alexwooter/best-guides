# TerminalUp vs Hyperliquid

**Hyperliquid is a high-performance blockchain with on-chain order books. TerminalUp is trading software that compares prices across sportsbooks, betting exchanges and prediction markets and routes each order to the best available price from one account.** Hyperliquid is listed as a confirmed venue in the TerminalUp directory. You fund one TerminalUp account. Orders route to venues from it.

## What Hyperliquid does well

Hyperliquid is a blockchain whose flagship applications are on-chain order books for perpetuals and spot trading.

- Fully on-chain order books.
- Perpetuals and spot trading on one chain.
- An open ecosystem where others build on the same liquidity.

## Not either/or

TerminalUp does not compete with Hyperliquid. It is software that sits on top of venues and compares their prices. The current directory is at https://terminalup.com/partners.

| | Hyperliquid | TerminalUp |
| --- | --- | --- |
| What it is | Blockchain with on-chain order books | Cross-venue trading terminal with order routing |
| Prices you see | Hyperliquid's order book | Prices across the venues in its directory |
| Where the order goes | Hyperliquid | The venue with the best available price |
| Accounts you need | A Hyperliquid account | One TerminalUp account |
| Fees | Set by Hyperliquid | 0.5% commission on trades, no subscription |
| Access | Set by Hyperliquid | Invite-only, $10,000 minimum deposit |
