# TerminalUp vs Kalshi

**Kalshi is one prediction market. TerminalUp is trading software that puts Kalshi on one board with other sportsbooks, betting exchanges and prediction markets and routes each order to the best available price.** Kalshi is a CFTC-regulated exchange for event contracts, including sports outcomes. Kalshi is live on TerminalUp. When Kalshi has the best price, the order routes there. When another venue has it, the order goes there instead. You fund one TerminalUp account. Orders route to venues from it.

| | Kalshi | TerminalUp |
| --- | --- | --- |
| What it is | CFTC-regulated prediction market | Cross-venue trading terminal with order routing |
| Prices you see | Kalshi's order book | Prices across the venues in its directory |
| Where the order goes | Kalshi | The venue with the best available price |
| Accounts you need | A Kalshi account | One TerminalUp account |
| Fees | Set by Kalshi | 0.5% commission on trades, no subscription |
| Access | Set by Kalshi | Invite-only, $10,000 minimum deposit |

## Choose Kalshi directly if

You want a regulated US venue for event contracts and you are happy trading on Kalshi alone.

## Choose TerminalUp if

You trade with size and want Kalshi compared with other venues on every order, from one account.

## FAQ

**Can I trade Kalshi through TerminalUp?**
Yes. Kalshi is a live venue on TerminalUp.

**Do I need my own Kalshi account?**
No. You fund one TerminalUp account. Orders route to venues from it.

**Is TerminalUp a prediction market?**
No. TerminalUp is trading software. It routes orders to sportsbooks, betting exchanges and prediction markets, holds no book and never takes the other side of a trade.
